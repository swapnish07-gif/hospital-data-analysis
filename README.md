# 🏥 Hospital Data Analysis

## 📌 Project Overview

This project analyzes hospital patient data using Microsoft Excel to identify important healthcare metrics, patient trends, and operational insights.

## 🛠️ Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Data Cleaning
- Data Analysis
- Data Visualization

## 🧹 Data Cleaning

The dataset was prepared for analysis by:

- Identifying missing values
- Removing duplicate records
- Checking inconsistent data
- Standardizing data formats
- Validating important fields

## 📊 Key Analysis

The project includes analysis of:

- Patient demographics
- Admission and discharge patterns
- Hospital departments
- Medical conditions
- Readmission Rate
- Patient distribution
- Key Performance Indicators (KPIs)

## 📈 Dashboard

An Excel dashboard will be created to present the key findings using:

- KPI Cards
- Charts
- Pivot Tables
- Interactive filters

## 💡 Key Insights

Insights will be added after completing the analysis and dashboard.

## 📁 Files

- `hospital data analysis.csv` — Original hospital dataset
- `Hospital_Data_Analysis.xlsx` — Excel analysis and dashboard

## 🎯 Project Objective

The objective of this project is to demonstrate practical skills in data cleaning, analysis, visualization, and extracting meaningful insights from healthcare data.
